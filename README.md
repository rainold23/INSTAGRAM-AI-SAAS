# Instagram AI SaaS

A production-ready foundation for a multi-tenant Instagram AI SaaS.

## Stack
- Next.js 15
- TypeScript
- Tailwind CSS
- React

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Environment
Copy `.env.example` to `.env.local` and add your Meta/Instagram and AI credentials when integrations are enabled.
